# 🛠️ Local Setup & Troubleshooting Guide

This guide covers the step-by-step local installation, dataset setup, and common troubleshooting steps for the EURS Underwater Vision project (Phase 1: Restoration).

## 📋 1. Prerequisites
- **OS**: Windows 10/11 (or Linux/macOS)
- **Python**: 3.9 - 3.11 (Recommended: 3.10)
- **Git**: Installed and added to system PATH
- **GPU**: NVIDIA GPU with CUDA support (Local testing done on T1000 16GB VRAM)

## 2. Step-by-Step Local Installation and Updation

cd eurs-underwater-vision

git pull origin main

git submodule update --init --recursive
